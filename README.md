# OIBSIP
This project is about E-Commerce Data Analysis. It focuses on analyzing an e-commerce dataset to understand sales performance, customer behavior, product performance, and revenue trends.

The project includes:
 Dataset Overview – examining the dataset structure, shape, and data types.
 Descriptive Statistics – summarizing important numerical and categorical variables.
 Time Series Analysis – identifying monthly and quarterly sales and revenue trends.
Customer Demographics Analysis – understanding customer characteristics and purchasing behavior.
 Product & Category Analysis – identifying top-selling products and high-revenue categories.
 Correlation Analysis – examining relationships between important numerical variables.
 Business Recommendations – providing practical suggestions to improve inventory management, reduce returns, and increase sales.
